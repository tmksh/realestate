マンション発信ツール 使用ガイド

画面のどこを押し、次に何が起きるかを役割ごとにまとめた手順です。データの持ち方やAPIの範囲は 仕様書 にあります。

1. はじめに

ポータルに出す前の未公開マンションを、管理会社が登録し、運営が確認して公式LINEの友だちに送ります。反応した人は運営の画面に残ります。

管理会社

自社の物件を下書きし、運営へ送ります。送ったあとは自分では直せません。

運営

内容を確認し、番地などを隠してから公式LINEへ送ります。会員と反応を見ます。

オーナー

割り当てられた物件だけを見ます。新しい物件の登録と配信はできません。

「公式LINEで配信」は本番の送信です 友だち全員のトークにテキストが届きます。見本を確認してから押してください。配信済みの物件は、もう一度送れません。

2. ログイン

  1. トップの「ログイン画面へ」を押すか、/login を開きます。
  2. メールアドレスとパスワードを入れて入ります。
  3. 運営は運営の画面、管理会社と利用中のオーナーは管理会社の画面に進みます。
  4. 終わるときは「退出」を押します。

空欄のままでは入れません。組み合わせが違うときは、その旨が出ます。LINEの友だちは、この画面では入れません。

3. 管理会社

自社の物件を登録し、運営の確認へ回します。

3-1. 物件を下書きする

  1. 「物件を登録」を開きます。
  2. マンション名、市区町村、町名、最寄駅、価格を入れます。これ以外は空でも残せます。
  3. 写真は画像のURLを貼り、「追加」を押します。ファイルのアップロードはありません。
  4. 「下書き保存」を押します。状態は下書きのままです。

入力したまま「物件一覧へ戻る」を押すと、破棄してよいか聞かれます。「編集を続ける」で画面に残ります。

3-2. 運営へ送る

  1. 必須が揃うと「運営へ送信」が押せます。足りない項目名が画面の下に出ます。
  2. 押すと状態が確認待ちになり、物件一覧へ戻ります。
  3. 確認待ち、配信準備、配信済みの物件は編集できません。直すときは運営に差し戻してもらいます。

3-3. 差し戻されたとき

  1. 物件一覧の「差戻し」で探します。物件を開くと、理由が赤枠で出ます。
  2. 直して、もう一度「運営へ送信」を押します。再び確認待ちになります。

3-4. 一覧とホーム

物件一覧は「すべて／下書き／確認待ち／差戻し／配信済み」で絞れます。配信準備だけのタブはありません。ホームには、下書きと差戻しの件数、確認待ち、配信済み、自社物件への反応が出ます。他社の物件は出ません。

4. 運営

届いた物件を確認し、公式LINEへ送り、反応を見ます。

4-1. 届いた物件を開く

  1. ホームの確認待ち、または左の「確認待ち」を開きます。
  2. 確認待ち、配信準備、差戻しが出ます。件があるときは「カード／一覧」で見た目を替えられます。この選択は配信履歴と共通です。0件のときは切替は出ません。
  3. 物件を開くと、管理会社が入れた元データが見えます。

4-2. 隠す項目と見本を決める

  1. 「詳細の目隠し」で、配信文から隠す項目を選びます。番地、部屋番号、マンション名、価格は見本の文面が変わります。確認画面の元データはそのままです。
  2. 管理費・積立と申し送りのトグルは、配信文にその項目が出ないため、見本の本文は変わりません。
  3. 配信形式は箇条書き、カード、PDFから選びます。右（狭い画面では下）の見本が変わります。PDFはファイル名の吹き出しです。
  4. 「添えるメッセージ」は見本の末尾に足されます。
  5. よければ「確認内容を保存」を押します。確認待ちだった物件は配信準備になります。
見本はトーク画面ではありません 友だちへ届くのはテキストです。カードやPDFの見た目は、トークには出ません。選んだ形式の名前は配信履歴に残ります。

4-3. 公式LINEで配信する

  1. 見本の文面を読みます。番地や価格を隠したかは、見本側で確認します。
  2. 「公式LINEで配信」を押します。友だち全員のトークに、そのテキストが届きます。
  3. 送れるのは確認待ちと配信準備だけです。下書きと差戻しは送れません。
  4. 成功すると配信詳細へ移り、ボタンは「配信済み」のまま押せなくなります。反応は自動では入りません。
送信できたあとに記録だけ失敗したとき 画面が、もう一度押さないよう案内します。同じ物件をもう一度送ると、友だちに二重で届くことがあります。

配信人数は、日本時間の前日に届けられる人数です。当日追加した友だちは入らないことがあります。取れないときは、登録されている会員数です。一覧の「反応」の数字とは別です。

4-4. 差し戻す

  1. 配信前の物件確認で、理由を書きます。空欄では「管理会社へ差し戻す」は押せません。
  2. 押すと確認待ちの一覧へ戻ります。LINEには送りません。
  3. 管理会社の物件詳細に、その理由が出ます。

配信済みの物件には、差し戻し欄は出ません。

4-5. 配信のあと

画面 見ること 操作
配信履歴 送った物件、日時、人数、形式、反応件数 カードか一覧で開き、詳細の見本と反応を見る
反応リスト 誰が、どの物件に、何を返したか 物件と種類（スタンプ／テキスト）で絞る。「CSVをコピー」で表をコピーする
LINE会員 友だちの表示名、流入、登録日 ブロックや友だち解除をすると流入が「離脱」になる。行は残る

スタンプはスタンプです。それ以外のメッセージはテキストです。同じ人の2通目以降も残ります。

4-6. 物件を運営が登録する

ホームの「物件を登録」から、管理会社と同じ入力ができます。運営のときは、管理会社の選択も必須です。一覧に無い会社は、名前を入れて「会社を追加」で作れます。

4-7. オーナーを発行する

  1. 「オーナーアカウント管理」を開きます。
  2. 氏名、メールアドレス、所属、見える物件を入れます。どれか空だと「アカウントを発行」は押せません。
  3. 発行直後は招待中です。招待メールは届きません。パスワードもここでは作りません。
  4. 「利用開始」で利用中にします。ダッシュボードのオーナー数は、利用中だけを数えます。
  5. 「表示を確認」で、その人に見える画面を自分のブラウザで見ます。再読み込みすると、運営のログインに戻ります。
  6. 見せたくなくなったら「利用停止」にします。停止中と招待中は、本人はログインできません。「表示を確認」も出ません。

5. オーナー

見えるのは、運営が割り当てた物件だけです。ホームに「物件を登録」は出ません。

  • 下書きと差戻しは編集して、運営へ再送信できます。
  • 確認待ち、配信準備、配信済みは閲覧のみです。
  • 配信、会員、オーナー管理の画面は開けません。

本人がメールアドレスとパスワードで入るには、利用中であることと、ログイン用のユーザーが別に紐づいていることが必要です。発行画面だけでは入れません。運営が見る「表示を確認」は、本人のログインではありません。

6. 状態の見方

画面の表示 意味 次にすること
下書き まだ運営へ送っていない 管理会社が追記し、送信する
確認待ち 運営の確認待ち。管理会社は編集できない 運営が目隠しして保存するか、差し戻すか、配信する
配信準備 目隠しと形式を保存済み。確認待ち一覧にも残る 見本を見て「公式LINEで配信」を押す
配信済み 友だちへ送った 履歴と反応を見る。再配信はしない
差戻し 運営が理由付きで返した。LINEには出ていない 管理会社が直して再送信する。確認待ち一覧にも残る

7. つまずいたとき

症状 確認すること
「運営へ送信」が押せない 画面下に出ている項目を入れる。運営が登録しているときは管理会社も選ぶ
物件を直せない 確認待ち以降はロックです。運営が差し戻すと、また編集できます
「公式LINEで配信」が押せない 下書き・差戻しは送れません。配信済みは再送できません
見本とトークの見た目が違う 見本は確認用です。届くのはテキストです
友だち追加したのに会員が増えない 追加の通知は、受け口を有効にしたあとの追加だけです。すでに友だちの人は、一度ブロックして追加し直すと一覧に出ます。受け口は https://mansion-hasshin.netlify.app/api/line/webhook です
配信人数が0、または友だち数と違う 表示は前日の対象数です。メッセージが届いていることとは別です
オーナーにログイン方法を伝えたが入れない 発行だけではパスワードはできません。利用中か、招待中・停止中かも確認します
